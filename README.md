🎰 Projeto Sinistrinha

Projeto acadêmico desenvolvido na disciplina de **Frameworks de Desenvolvimento**. Trata-se de uma simulação de máquina caça-níquel, sem utilização de dinheiro real, criada para aplicar conceitos de desenvolvimento Full Stack, arquitetura de microsserviços, comunicação em tempo real e automação de entrega.
A aplicação possui autenticação JWT, realização de jogadas por API, atualizações por WebSockets, jackpot progressivo, sistema de níveis e um painel administrativo para acompanhamento de métricas.

Sua arquitetura é composta por:

- Frontend desenvolvido com React, TypeScript e Vite.
- Backend principal construído com Django.
- Motor probabilístico independente desenvolvido com FastAPI.
- Comunicação em tempo real com Django Channels e WebSockets.
- Persistência de dados com Supabase e PostgreSQL.
- Sincronização de dados e jackpot utilizando Redis.
- Conteinerização com Docker e Docker Compose.
- Pipeline de CI/CD com GitHub Actions para testes, validação do frontend e verificação dos contêineres.
